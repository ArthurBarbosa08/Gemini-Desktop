Gemini Desktop

Cliente desktop não-oficial do Google Gemini com integração de workspace local — selecione uma pasta, injete o código no chat e comece a desenvolver com contexto completo.

App ID com.gemini.desktop Plataforma Windows Empacotamento Portable Sessão Persistente

Funcionalidades

💬

Interface nativa do Gemini

Carrega o Gemini completo em janela desktop com sessão de login persistente entre aberturas.

📂

Injeção de projeto

Botão dedicado na barra do Gemini que abre o seletor nativo de pastas do Windows.

🔍

Leitura recursiva

Varre a estrutura do projeto, ignora node_modules/.git e lê arquivos de código automaticamente.

📋

Contexto formatado

Monta o prompt com estrutura de arquivos e conteúdo em bloco Markdown — pronto para o Gemini analisar.

🧹

Filtros inteligentes

Ignora diretórios pesados e limita arquivos a 100KB. Suporta JS, TS, Python, Rust, Go, Java, C/C++ e mais.

🪟

Distribuição portable

Empacotado como executável portable sem necessidade de instalação — basta rodar.

IA com contexto

O aplicativo Electron cria uma janela isolada que carrega o Gemini no navegador Chromium embutido. Quando a página termina de carregar, um script de injeção insere um botão diretamente na interface do Gemini.

  • O usuário clica no botão "Inserir Pasta do Projeto"
  • O seletor de pastas nativo do Windows abre
  • Arquivos de código são lidos recursivamente (ignorando node_modules, .git, dist, .gemini, etc.)
  • O conteúdo é formatado como prompt Markdown e injetado na caixa de texto do Gemini
  • O usuário envia e recebe análise completa do projeto

Instalação e build

Pré-requisitos

Node.js 18+ e npm instalados.

Instalar dependências

Na raiz do projeto, execute: npm install

Rodar em desenvolvimento

Execute npm start para abrir o app. O Gemini será carregado e o botão de injeção aparecerá após o carregamento da página.

Gerar executável

Execute npm run dist para gerar o .exe portable via electron-builder.

Limitações conhecidas

⚠️

Não-oficial: Este projeto não é afiliado ao Google. Mudanças na interface web do Gemini podem quebrar a injeção de scripts a qualquer momento.

⚠️

Seletor de arquivos: Apenas o seletor nativo do Windows está implementado. Mac/Linux não são suportados no build atual.

⚠️

Limite de contexto: Arquivos acima de 100KB são ignorados e pastas como node_modules, .git, dist e .gemini são excluídas da leitura.

⚠️

Login: Requer login manual no Google na primeira execução. A sessão é mantida pelo partition do Electron.

Feito para desenvolvedores que querem usar o Gemini com o contexto completo do seu projeto.
